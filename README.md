## 🌟 Overview

**PaperInk** is a simple and lightweight web application that transforms digital text into a handwritten-style document.

Instead of manually writing pages, users can type or paste their content, customize the handwriting appearance, select a paper design, choose an ink color, and preview the result before exporting it.

The project was created with a focus on **simplicity, customization, and a clean user experience**.

### ✨ What can you do with PaperInk?

- 📝 Type or paste your content
- ✍️ Choose a handwriting style
- 📄 Select different paper designs
- 🎨 Customize ink color
- 🔤 Adjust handwriting size
- 🖋️ Upload your own `.ttf` handwriting font
- 🖼️ Upload a custom paper background
- 👀 Preview your document before exporting
- 📥 Export your handwriting as PDF
- 🖼️ Download the result as PNG
- 🖨️ Print your handwritten document directly

## 🎯 Why PaperInk?

PaperInk was designed around a simple idea:

> **What if typed text could look more personal?**

Whether you're creating handwritten-style notes, preparing a document, experimenting with typography, or simply giving digital text a more personal appearance, PaperInk provides the tools directly in the browser.

No complicated setup.  
No backend required.  
Just open the application and start writing.

### Core Technologies

- **HTML5** for the application structure
- **CSS3** for styling and layout
- **JavaScript** for application logic and interactions
- **HTML Canvas** for rendering/exporting handwritten content
- **jsPDF** for PDF generation
- **html2canvas** for image-based export
